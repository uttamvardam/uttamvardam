# 📌 Featured Projects

## 🚗 Vehicle Damage Detection

**Deep Learning | PyTorch | ResNet50 | Computer Vision | Streamlit**

Built an automated vehicle damage classification system for **VROOM Cars**.

* Classified vehicle condition into **6 categories**: Front/Rear × Normal/Breakage/Crushed
* Trained and evaluated models on **2,300+ vehicle images**
* Compared Custom CNN, CNN with regularization, EfficientNet-B0, and ResNet50
* ResNet50 achieved **79.48% validation accuracy**
* Used **Optuna** for hyperparameter tuning
* Deployed the model using **Streamlit** for real-time prediction

---

## 💳 Credit Risk Prediction

**Machine Learning | XGBoost | Scikit-learn | SMOTE | WOE/IV**

Developed an end-to-end credit risk prediction system using customer, loan, and credit bureau data.

* Performed data preprocessing, EDA, and feature engineering
* Applied **VIF analysis** and **WOE/IV transformation**
* Addressed class imbalance using **SMOTE and Tomek Links**
* Evaluated Logistic Regression, Random Forest, and XGBoost
* Applied **Optuna** for hyperparameter optimization
* Final Logistic Regression model achieved:

  * **93% Accuracy**
  * **0.83 F1-score**
  * **0.98 ROC-AUC**
* Deployed the solution using Streamlit for real-time credit risk assessment

---

## 🏥 Insurance Premium Prediction

**Machine Learning | XGBoost | Linear Regression | Streamlit**

Developed an end-to-end machine learning system to predict health insurance premiums.

* Used customer attributes including **age, BMI, income, smoking status, medical history, and insurance plan**
* Performed data cleaning, EDA, feature engineering, encoding, scaling, and VIF analysis
* Applied different modeling strategies for different age groups
* Used **Linear Regression** for younger customers
* Used tuned **XGBoost** for other age groups
* Deployed the final solution using Streamlit for real-time premium prediction
